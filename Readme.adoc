A https://sequel.jeremyevans.net/[Sequel] extension that retires pooled connections once they pass a maximum age.

See link:documents/motivation.adoc[the motivation] for why it exists.

== Usage

[source,ruby]
----
DB = Sequel.connect(url, connection_max_lifetime: 90)
DB.extension :pg_reaper
----

* `connection_max_lifetime` is in seconds and defaults to 120
* The age is checked as a connection is checked out of the pool, so the cost is one hash lookup
* A connection that is too old is disconnected and replaced before your code sees it
* A connection already checked out, such as inside a transaction, is never reaped
* Idle connections are not closed in the background, see <<Idle connections>>
* Single and sharded single pools are not supported

The lifetime can also be changed at runtime with `DB.pool.connection_max_lifetime = 60`.

== Idle connections

Nothing in this extension, or in Sequel's `connection_validator`, closes an idle socket in the background.
Both act when a connection is checked out:

* `pg_reaper` replaces any connection older than `connection_max_lifetime`, however long it sat idle
* `connection_validator` runs a query on connections idle longer than `connection_validation_timeout`
  and replaces the ones that fail

For a pgdog rollout `pg_reaper` is enough. A connection from before the pod got SIGTERM is older than the
lifetime by the time it could be used against a dead pod, so it is replaced first.

Load `connection_validator` as well to cover connections that die for other reasons, such as a pgdog crash
or a network failure:

[source,ruby]
----
DB = Sequel.connect(url, connection_max_lifetime: 120)
DB.extension :connection_validator, :pg_reaper
DB.pool.connection_validation_timeout = 30
----

* `connection_validation_timeout` is how long a dead connection can go undetected, set it to `-1` to validate on every checkout, which costs a query each time
* Load order does not matter

[WARNING]
----
A connection checked out for longer than the time left before the pod terminates is not interrupted, keep transactions short
----

== Development

[source,sh]
----
mise install
bundle exec rake
----

Tests use `Sequel.mock`, so no database is needed.

Commits and PR titles must follow {conventional-commits} to be included in the changelog and release notes.
The hooks in `.githooks` enforce it, and `mise run setup` enables them.

Releases are cut by https://github.com/googleapis/release-please[release-please] and published to rubygems.org.
